# Live32 Channel v0.3.0 UI revision

The v0.3 editor is organised like a physical digital console rather than like
four plug-in panels.

- CONFIG/PREAMP and GATE occupy the left side.
- EQUALISER and DYNAMICS hardware controls occupy the centre.
- EQ and compressor visualisation live together in a right-hand CHANNEL DISPLAY.
- EQ MODE is beside the hardware controls.
- Dynamics display focuses on threshold, ratio and knee, with makeup shown as a
  value rather than shifting the transfer curve.
- Readouts use short desk-style formatting rather than raw floating point text.

The audio DSP is unchanged from v0.2.2.
